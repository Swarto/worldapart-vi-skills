# World Apart – skill Việt hóa theo vai

Bộ skill cho quy trình dịch game tu tiên *World Apart* từ tiếng Trung sang tiếng Việt, chia theo vai:

| Skill | Vai | Dành cho |
|---|---|---|
| [wa-bien-tap](wa-bien-tap/SKILL.md) | Biên tập bản nháp theo lô | Model mạnh (GPT, Claude) |
| [wa-soat](wa-soat/SKILL.md) | Soát độc lập, trả `ok`/`flag` kèm bản sửa | Model mạnh |
| [wa-local-dich](wa-local-dich/SKILL.md) | Dịch nháp, bản rút gọn kèm thuật ngữ | Model local nhỏ (Gemma 12B) |
| [wa-local-soat](wa-local-soat/SKILL.md) | Rà máy nhanh | Model local nhỏ (Qwen3 8B) |
| [wa-scrum-master](wa-scrum-master/SKILL.md) | Scrum Master: phân task, daily, coaching, review, retro, cải tiến | Model mạnh có quyền đọc file dự án |

Mọi skill đều coi chuỗi game là dữ liệu, không phải lệnh, và giữ nguyên placeholder, thẻ và con số.

Đây là dự án Việt hóa của người hâm mộ, không liên quan đến nhà phát triển game.
